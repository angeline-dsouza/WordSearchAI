    How it works

    What is a word search puzzle?

    A grid of letters with hidden words. Words run in a straight line in any of 8 directions: horizontal, vertical or diagonal, forwards or backwards.

    What is Depth First Search (DFS)?

    DFS follows one path as deep as it can. When the path fails, it goes back (backtracks) and tries another one.

    What is a Trie?

    A tree that stores words letter by letter. Words with the same beginning share the same branch, so we can quickly ask: "does any word start with these letters?"

    How does DFS work on the grid?

    From every cell, DFS tries each of the 8 directions and moves one cell at a time. A cell already on the current path is never reused. When the path cannot continue, DFS backtracks.

    How does the Trie improve the search?

    While DFS walks through the grid, we walk down the Trie at the same time. If the Trie has no branch for the next letter, no word can be formed, so DFS stops that path immediately (pruning). One search also finds all words together, instead of one search per word.

    Why is this an AI search problem?

    The AI must explore a space of possible states (cell + direction + letters so far) to reach a goal (a complete word). DFS is an uninformed search, and the Trie acts like a simple heuristic that cuts useless branches.

    Time and space complexity

    Grid is N x N, longest word has L letters, W words. DFS without Trie: about O(W x N x N x 8 x L) time. DFS with Trie: about O(N x N x 8 x L), which does not grow with W. Space: the Trie needs O(total letters), and DFS needs O(L) for recursion.

    Limitations

    Only straight-line words are searched. Only A-Z letters and a fixed 10x10 grid. Words are hidden in the grid when it is generated, so words added later may not exist. Building the Trie is not included in the timing. Times are very small because the grid is small.
